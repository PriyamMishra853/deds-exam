@@HOWTO@@

How to use the Logisim files

  1. Open DE_Lab_All_Circuits.circ in Logisim 2.7.1 (File → Open). Every question is a separate circuit in the explorer panel on the left (Q01 ... Q78). Double-click a circuit to open it. The same circuits are also saved one per file in the Individual_Circuits folder.
  2. Select the Poke tool (hand icon) and click an input pin to change it between 0 and 1. Output pins show the result immediately.
  3. Circuits whose names start with Helper - (full adder, decoder, multiplexer, flip-flops ...) are the sub-circuit blocks used inside bigger circuits. Double-click a block in a circuit to look inside it.
  4. Sequential circuits (Q68-Q78): a latch built from gates starts in an unknown state. Flip-flops and counters have a CLR input: set CLR = 1 and back to 0 first, then toggle CLK. Master-slave JK/T/SR flip-flops change when CLK goes 1 → 0; the D flip-flop and shift register change when CLK goes 0 → 1. To run a counter automatically you may replace the CLK pin with a Logisim Clock component and press Ctrl+K.
  5. All circuits use ordinary gates, wires, pins and tunnels, so they can be edited freely - move, delete or add gates exactly as in your own lab work.
  6. Every circuit was checked automatically by loading the .circ file into Logisim's own simulation engine and comparing every output with the expected truth table or sequence.

Aim: To verify the truth tables of the basic logic gates AND, OR, NOT, NAND, NOR, XOR and XNOR.

Theory: Logic gates are the building blocks of digital circuits. AND gives 1 only when all inputs are 1; OR gives 1 when any input is 1; NOT inverts. Notes: The 7-Segment Display

A 7-segment display shows a decimal digit using seven LED bars named a (top), b (upper right), c (lower right), d (bottom), e (lower left), f (upper left) and g (middle); many displays also have a decimal point dp.

  • Common cathode (CC): all LED cathodes are tied to ground, so a segment glows when its input is 1 (driven by an active-high decoder such as IC 7448). The Logisim 7-Segment Display behaves this way.
  • Common anode (CA): all anodes are tied to +V, so a segment glows when its input is 0 (active-low decoder such as IC 7447). The CA truth table is simply the complement of the CC table.
  • A BCD to 7-segment decoder is a combinational circuit with 4 inputs (A B C D, A = MSB) and 7 outputs. Inputs 1010-1111 never occur in BCD, so they are don't-cares (X) in every K-map.
  • Each segment output is designed separately: write the truth table, put the 1s (and Xs) on a 4-variable K-map, group, and read the minimal SOP. Product terms common to several segments are shared (multiple-output design).
  • The 3-bit version (Q54) uses x y z (digits 0-7) and 3-variable K-maps; in the class notes these outputs are called F1...F7.
